# 회의 녹음·전사 (PC + 휴대폰, 서버 없는 웹앱)

녹음 → 기기에 즉시 보관 → Google Drive 자동 저장 → 무료 전사 → 녹취록(Google Docs) 자동 저장.

## 파일
`index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.svg` — 이 폴더 그대로 HTTPS 정적 호스팅에 올리면 됩니다.
(마이크는 HTTPS 또는 localhost에서만 동작합니다.)

## 1. 호스팅 (무료, 택1)
- GitHub Pages / Cloudflare Pages / Netlify 에 폴더를 올립니다. 주소 예: `https://내이름.github.io/recorder/`
- 기관 내부 보안 정책상 외부 호스팅이 어렵다면 내부 웹서버(HTTPS)에 올려도 됩니다.

## 2. Google Drive 연동용 OAuth 클라이언트 ID 만들기 (1회, 무료)
1. console.cloud.google.com → 새 프로젝트 만들기
2. API 및 서비스 → 라이브러리 → **Google Drive API** 사용 설정
3. OAuth 동의 화면 → 외부(또는 내부) 선택 → 앱 이름 입력 → 테스트 사용자에 본인 Google 계정 추가
4. 사용자 인증 정보 → 사용자 인증 정보 만들기 → **OAuth 클라이언트 ID** → 유형 "웹 애플리케이션"
5. **승인된 JavaScript 원본**에 1번에서 만든 주소(예: `https://내이름.github.io`)를 추가
6. 발급된 클라이언트 ID를 앱의 `설정` 칸에 붙여넣기

요청 권한은 `drive.file`(이 앱이 만든 파일만 접근)이라 기존 Drive 파일은 보지 못합니다.
Drive에는 `회의녹음/날짜 제목/` 폴더가 생기고 음성 파일(구간별)과 `녹취록`(Google Docs)이 저장됩니다.

## 3. 무료 전사
- **Groq Whisper API(기본 권장)**: console.groq.com 에서 무료 키 발급(gsk_...) → 설정에 입력. 한국어 정확도가 좋고 빠르며 폰·PC 모두 가능, 화자 구분은 없습니다. 5분 구간마다 전사하므로 1~2시간 회의도 녹음하는 동안 거의 실시간으로 처리됩니다. 무료 등급에는 "시간당 처리할 수 있는 음성 길이" 제한이 있어(수치는 Groq 콘솔의 Limits에서 확인), 한도에 걸리면 해당 구간만 1분 뒤 자동 재시도합니다. 구간 문서 앞에 `[00:05:00]` 같은 시간표시가 붙어 AI에 올려 정리시키기 좋습니다. 음성이 Groq 서버로 전송되므로 기밀 회의는 아래 브라우저 Whisper를 쓰세요.
- **Gemini API(화자 구분 가능)**: aistudio.google.com 에서 무료 키 발급 → 설정에 입력. 무료 등급은 호출 제한이 있고, 무료 등급 입력 데이터는 Google 제품 개선에 쓰일 수 있으므로 **기관 보안 자료·개인정보가 있는 회의에는 사용 전 확인**하세요. 모델명이 단종되면 설정의 모델명만 바꾸면 됩니다.
- **브라우저 내 Whisper**: 완전 무료, 음성이 외부로 나가지 않음. 대신 화자 구분이 없고, 최초 1회 약 250MB 모델을 내려받으며 휴대폰에서는 느립니다(PC 권장). 녹음이 끝난 뒤에 처리됩니다.

## 음성 파일 전사 (이미 녹음된 파일)
화면의 "파일 선택해서 전사"로 mp3·m4a·wav·mp4 등을 고르면, 5분 단위로 나눠 전사하고 같은 방식으로 Drive에 `원본 파일 + 녹취록`을 저장합니다. 전사 방식은 설정에서 고른 것을 따릅니다.
- 긴 파일(1~2시간)은 브라우저가 파일을 한 번 풀어서 처리하므로 **PC 권장**입니다. 폰에서는 메모리가 부족해 실패할 수 있습니다(24MB 이하 파일은 Groq 선택 시 원본 그대로 전송하는 대체 경로가 있습니다).
- 변환용 임시 조각은 전사 후 자동 삭제되고, 원본 파일만 Drive에 올라갑니다.

## 4. 폰에 설치
- 안드로이드 Chrome: 메뉴 → "홈 화면에 추가/앱 설치"
- iPhone Safari: 공유 → "홈 화면에 추가"

## 전화가 오면 어떻게 되나요? (중요)
웹 브라우저는 전화가 오면 OS가 마이크를 가져가는 것을 막을 수 없습니다. 이 앱은 "끊기지 않게"가 아니라 **"끊겨도 잃지 않고 자동으로 이어가게"** 설계했습니다.

- 녹음은 2초마다 기기에 저장되고, 5분(설정)마다 별도 파일로 나뉘어 Drive에 올라갑니다. 끊겨도 그 시점까지는 안전합니다.
- 마이크가 끊기면 자동 감지 후 2.5초마다 재연결을 시도하고, 돌아오면 이어서 녹음합니다. 녹취록 끝에 "녹음 중단 구간" 시각이 기록됩니다.
- 전화를 받지 않아도 **벨이 울리는 동안**은 마이크가 넘어갈 수 있어, 그 구간 소리는 녹음되지 않을 수 있습니다(특히 iPhone). 안드로이드는 대체로 덜 끊깁니다.
- 가장 확실한 방법: 녹음 전에 휴대폰을 **방해 금지 모드**로 두면 벨이 울리지 않아 대부분 끊기지 않습니다. 중요한 회의는 PC로 녹음하세요.
- 녹음 중에는 화면을 켜 둔 채 이 탭을 앞에 두세요(화면 꺼짐 방지 기능이 자동 적용됩니다). iPhone은 화면 잠금·앱 전환 시 녹음이 멈출 수 있습니다.

## 알아둘 점
- Google 로그인 토큰은 약 1시간마다 만료됩니다. 자동 갱신이 막히면 녹음은 기기에 계속 쌓이고, 앱을 열어 로그인하면 밀린 파일이 한꺼번에 올라갑니다.
- 앱이 비정상 종료돼도 다음 실행 때 저장된 조각을 복구합니다.
- 기록 목록에서 음성·녹취록을 직접 내려받을 수 있습니다. "이 기기에서 삭제"는 Drive 사본에 영향이 없습니다.
- 분할 간격은 기본 5분(최대 10분)입니다. Gemini를 쓸 때만 6분 이하로 두세요.
- 통화 자체(상대 목소리)를 폰에서 녹음하려면 스피커폰 상태에서 다른 기기로 녹음해야 합니다. 법적·동의 문제도 확인하세요.
